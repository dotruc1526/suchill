# Approval Briefs — Bản duyệt nhanh

Thư mục này dành cho product owner hoặc người duyệt không cần đọc toàn bộ tài liệu kỹ thuật.

Mỗi phase có hai tài liệu:

1. **Approval brief:** đọc trước, dùng để hiểu và đưa ra quyết định.
2. **Full spec:** tài liệu chi tiết để frontend, backend, content và QA cùng triển khai.

## Cách duyệt

1. Đọc approval brief trong khoảng 5–10 phút.
2. Xem ví dụ minh họa.
3. Kiểm tra phần “Bạn đang duyệt điều gì?”.
4. Chọn duyệt toàn bộ hoặc ghi mục muốn thay đổi.

Bạn không cần hiểu TypeScript, database, state machine hoặc API để duyệt product decision.
