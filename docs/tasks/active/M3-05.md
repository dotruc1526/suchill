## Scope

- In scope: delivered question set; complete answer selection; practice/scored submission; per-question trusted feedback; practice retry; scored score/pass presentation; stable operation ID per retryable submit; loading/error/double-submit/accessibility states.
- Out of scope: answer-key delivery, client grading, completion/reward/XP, question authoring, analytics and App/journey integration.
- Trust rule: UI displays only service receipts and never derives correctness, score, pass or reward from selected options.
