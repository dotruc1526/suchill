## Mục tiêu
Đập đi xây lại cấu trúc API Backend bị lỗi bảo mật từ PR #14. Xây dựng nền tảng API vững chắc, có mã hóa và xác thực.

## Acceptance Criteria
- [ ] Xóa bỏ code cũ trong `server.js`.
- [ ] Tích hợp `bcryptjs` để mã hóa mật khẩu người dùng vào DB.
- [ ] Tích hợp `jsonwebtoken` (JWT) để cấp token khi Login.
- [ ] Mọi endpoint thay đổi dữ liệu (như cộng XP) phải có middleware check token `authenticateToken`.
- [ ] `userId` phải được giải mã từ Token, tuyệt đối không nhận từ Request Body để chống hack.
- [ ] Điểm `xpGain` phải được tính toán hoặc fix cứng trên Server, không để Client quyết định.
- [ ] Code không lưu DB runtime (database.sqlite) vào Git.
